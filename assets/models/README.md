# Modelos GLB propios

El Laboratorio de RV carga por defecto `scratch-cat.glb`, aportado para este proyecto. Antes de redistribuirlo o publicarlo, confirma que tienes derecho a hacerlo y conserva la atribución/licencia exigida por la fuente. El proyecto no afirma afiliación ni respaldo oficial de Scratch.

En la versión pública actual no hay Ajustes docentes para cambiar el modelo. Para sustituirlo, sube el `.glb` a esta carpeta y actualiza la ruta por defecto en el código de `index.html` y en la construcción de la escena A-Frame. Respeta mayúsculas y minúsculas. Las rutas relativas funcionan en GitHub Pages; una URL HTTPS externa puede estar sujeta a CORS.
